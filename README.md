# Onboarding-Zusammenfassung

Interaktive Checkliste für Baubegleiter: Nach dem Kunden-Onboarding die besprochenen Punkte ankreuzen bzw. ausfüllen – daraus entsteht automatisch die Kundenmail (Outlook-Entwurf oder Kopieren).

- Die Seite ist eine einzelne Datei: `index.html`
- Alle Eingaben bleiben im Browser des Nutzers. Es werden keine Kundendaten gespeichert oder übertragen.
- Veröffentlicht über GitHub Pages (Branch `main`, Ordner `/`).
